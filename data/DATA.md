# 数据说明

本目录的 `jiangsu_admission_data.sql` 是 **志愿领航 Agent** 使用的江苏省高考数据，由作者自行收集整理，自愿公开，**仅供学习与研究使用**。

> 这是**真实收集整理的数据，不是模拟数据**；但整理过程中可能存在遗漏或错误，**不构成任何志愿填报建议**，实际填报请以江苏省教育考试院及各高校官方发布为准。

## 内容

| 表 | 行数 | 说明 |
|---|---|---|
| `schools` | 1576 | 院校基础信息（层次、城市、985/211/双一流标签等） |
| `admission_groups` | 6967 | 专业组（选科要求、专业关键词、招生计划等） |
| `admission_records` | 22565 | 各专业组历年最低分、最低位次（2023–2025）及 2026 招生计划 |
| `score_rank_rows` | 3107 | 一分一段表，用于跨年位次等效换算 |

不包含：用户、对话、方案、Agent 运行记录，也不包含政策原文文件。政策部分只提供向量库（`policy_vectors.sql`：12 份政策文件的元信息和 193 个文本片段及其向量），不提供政策原文文件。

## 来源

作者自行搜集整理，仅用于实验。

## 需要注意的地方

1. **含少量示例数据**：项目自带 10 个示例专业组（id 形如 `seu-cs-04`，来自 `backend/app/seed_data/jiangsu_physics_seed.json`），用于演示和测试，**不保证与官方数据一致**，请勿作为真实参考。
2. 数据仅覆盖江苏省，其他省份的评测用例只用于测试对话理解，没有对应数据。
3. 项目 README 与评测报告中的指标，均是在这份（完整）数据上跑出的结果。
