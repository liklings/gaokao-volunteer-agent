# 专项计划（国家专项 / 高校专项 / 地方专项）

## 三类专项计划的区别

- **国家专项计划**：面向连片特困地区、国家扶贫开发工作重点县的考生，由教育部统一分配名额到中央部委高校和各省属重点高校，通常安排在**本科提前批**或**本科批之前单独一个批次**投档，具体位置以当年本省招生办公布的批次设置为准。
- **高校专项计划**（俗称"筑梦计划"）：由具备资格的重点高校自主招生，除了户籍/学籍条件，通常还要求考生**本人及父母（或法定监护人）连续多年在当地实际居住**，多数高校还会有一轮初审+校测（笔试/面试），不是单纯按分数投档，笔试面试成绩会计入综合评价。
- **地方专项计划**：由各省属重点高校面向本省农村和贫困地区户籍考生招生，名额和资格条件由各省自行制定，跨省考生一般不适用。

## 报考资格的三个常见误区

1. **"户籍在当地就一定能报"**——三类计划基本都同时要求**户籍+学籍**（部分还要求实际就读年限），单有户籍、学籍在外地读书通常不满足条件；具体年限要求以当年本省考试院发布的专项计划报考资格文件为准，不同省份、不同年份可能有调整。
2. **"专项计划分数线比普通批低很多"**——专项计划的录取分数确实通常低于同校同专业组的普通批，但降分幅度因校因专业而异，不是固定的"降多少分"，需要具体查该校该专业组当年的专项计划录取数据，不能直接套用普通批数据做估分参考。
3. **"报了专项计划就不能再报普通批"**——专项计划通常安排在单独批次或普通批之前投档，如果专项计划没被录取，考生仍然可以正常参加后续批次（含普通批）的投档，两者不冲突，但要注意如果专项计划批次被录取，会直接结束本轮投档，无法再参与后续批次。

## 给 Agent 的实践建议

回答考生"我能不能报专项计划"这类问题时：
- 先确认考生的户籍/学籍所在地是否在专项计划的地区名单内（这个名单本身会逐年调整，不确定时应明确告知考生"以当年本省考试院公布的专项计划实施区域名单为准"，不要凭旧年份的记忆给出肯定答案）。
- 高校专项计划涉及校测环节，要提醒考生关注该校的报名时间、材料提交截止日期、初审结果公布方式——这些流程性节点经常是考生和家长最容易错过的部分。
- 不要把专项计划的录取分数线当作普通批分数线的参考基准，两者不可直接类比。
