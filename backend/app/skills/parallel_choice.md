# 平行志愿投档规则

## 核心机制："一分一段、位次优先、遵循志愿、一轮投档"

平行志愿不是"同时看你填的所有志愿再挑一个最好的给你"，而是严格按下面的顺序执行：

1. **分数（位次）排序**：先把本省本科类（物理类/历史类）所有考生按照分数从高到低排出一个位次（同分再按语文、数学等单科成绩细排，规则各省略有差异）。
2. **逐个考生投档**：从位次第一名的考生开始，按 Ta 自己填报的志愿顺序（比如A、B、C……）**依次检查**，一旦某个志愿院校专业组当年的招生计划还有名额且该考生分数达到投档要求，**立即投档到这一个志愿，不再检查后面的志愿**——这就是"遵循志愿"：一轮里只要投出去了，后面填的志愿全部作废，不会被拿去和其他志愿比较"哪个更好"。
3. **对所有考生重复上一步**，直到这一轮全部考生都处理完。

理解这个机制最关键的一点：**平行志愿是"一轮定档"，不是"多轮比较"**——不存在"先看看A校录不录得上、录不上再看B校"这种试探性的多轮机制，一旦投档到某一个志愿，即便后面志愿的学校原本更满足考生心愿，也已经没有机会了。

## "冲稳保"志愿梯度怎么排

正是因为"一投档就定、不会回头看后面志愿"，志愿顺序的梯度设计才重要：

- **冲**：分数/位次略高于目标院校专业组往年录取线（有一定概率但不确定能上）的志愿，放在最前面几个。
- **稳**：分数/位次跟目标院校专业组往年录取线比较接近、被录取概率较大的志愿。
- **保**：分数/位次明显高于目标院校专业组往年录取线、基本确定能被录取的志愿，放在最后作为兜底，避免"一所都没投上、直接掉到下一批次或征集志愿"的最差结果。

## 给 Agent 的实践建议

- 跟考生解释"为什么志愿顺序很重要"时，要点出"一轮投档、遵循志愿"这个机制本身，而不是笼统地说"顺序很重要"——很多考生和家长对平行志愿的误解正是以为"没投上第一个还会看第二个跟别人比"。
- 生成志愿建议列表时，如果候选里既有冲的、也有稳的、保的，应该在文字说明里标出每个候选属于哪一档，方便考生理解为什么这么排序，而不是只给一个纯按概率降序的列表。
- 不要把"平行志愿"和"顺序志愿"（老高考部分省份仍在使用的另一种投档规则，第一志愿优先级远高于后续志愿）混为一谈，两者投档逻辑完全不同；如果不确定考生所在省份用的是哪种投档规则，应明确询问或提醒考生核实。
