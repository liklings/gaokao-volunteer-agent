# 专业调剂（"服从专业调剂"该不该勾）

## 调剂在赌什么

在一个院校专业组内部，考生通常会填报多个专业志愿（比如"计算机科学与技术""软件工程""电子信息工程"……），如果：

- 该专业组的分数达到了投档线（被这个专业组"投档"成功），
- 但考生填报的**组内几个专业志愿分数都不够**（比如都被更高分的考生占满了），

这时候如果考生**勾选了"服从专业调剂"**，招生高校会把这名考生调剂到该专业组内**还有剩余名额的其他专业**，考生仍然被这所学校录取，只是专业不是自己填报的那几个之一；如果**没有勾选服从调剂**，则会被**退档**（也叫"投档后退档"）——这一轮直接掉到征集志愿或下一批次，且退档后不能重新参与本轮同批次的其他志愿。

## 该不该勾"服从调剂"，权衡的是什么

这是一个"保学校 vs 保专业"的取舍，没有统一正确答案，Agent 应该呈现权衡本身，而不是替考生做决定：

- **倾向勾选**：更看重"能上这所学校/这个层次"本身，对专业没有特别强烈的执念，或者该专业组内的专业本身差异不大（比如都是同一个大类下的相近专业）。
- **倾向不勾选**：对某个具体专业有明确的、不可替代的执念（比如立志学医、必须是某个特定专业方向），宁可不上这所学校也不想被调剂到完全不相关的专业，且分数/位次留有余地、退档后进入下一批次或征集志愿仍有把握录取到能接受的选择。

## 给 Agent 的实践建议

- 不要用"建议勾选"或"建议不勾选"这种一刀切的措辞回答"我要不要服从调剂"，应该先问清楚（或者基于已收集的 major_keyword、city_pref 等条件推断）考生对专业的执念程度和分数余量，再分情况说明两种选择各自的后果。
- 明确讲清楚"不服从调剂 + 组内专业分数不够 = 退档"这个因果链条，很多考生和家长对"退档"具体是什么、会掉到哪一步没有清晰认识，容易只关注"专业调剂"这四个字表面含义。
- 如果考生问的是某个具体专业组"调剂概率大不大"，应如实说明这类信息数据库/工具里通常没有直接数据支持（历年调剂人数一般不公开到院校专业组这一级），不要编造具体概率数字。
